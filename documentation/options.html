All options

Every option of the parameter classes, in one place

Reference tables of every option of the NLSA Python toolkit’s parameter classes, grouped by calculation block, with types, allowed values, defaults and descriptions, generated from the source code of version 0.4.

This page collects the option tables of the calculation block pages. They are generated from the source code of version 0.4: option names, types, allowed values and defaults are those of the code, and every documented option has been checked to exist. required means that the option has no default.

Classes from the toolkit are imported as shown in each table’s caption. PredPars, TrainPars, TestPars and Pars are defined in each example script, and differ slightly between the scripts.

EXPERIMENT chooses the configuration to run. It is a member of the script’s Experiment enumeration, from which from_experiment() builds the parameters of the run (together with CONE_KERNEL and KERNEL_NORMALIZATION); see Experiments. The kernel analog forecasting script runs ELNINO_2027_FROM_ERA5_NINO34SST, the Koopman script ENSO_FROM_ERA5_IPSST.

KoopmanParsDiff (nlsa.jax.koopman, defined in src/nlsa/koopman.py)
Option Type or values Default Description
fd_order 2 or 4 or 6 or 8 required Order (2, 4, 6 or 8) of the central finite differences used for time derivatives along the trajectory. Reserve fd_order // 2 samples before and after with num_before and num_after.

gram_batch_size int or None None Batch size for the inner products that form the generator matrix.
